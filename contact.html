Technical support

Report a problem

If the converter fails with a non-sensitive test image, or if you find a broken page, submit a public issue in the project repository.

Open GitHub Issues

Before reporting

  • Do not attach private, medical, financial, identity, or copyrighted photos.
  • Include your browser, device, and operating-system version.
  • Describe the error message and whether a different HEIC file worked.
  • Check that JavaScript is enabled and the browser is current.

Privacy questions

Review the privacy page for details about local conversion, the converter library, and optional analytics.

Security reports

Please avoid publishing exploit details or personal data. Start with a short issue that requests a private contact path.
