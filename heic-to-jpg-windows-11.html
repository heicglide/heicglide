Why Windows struggles with HEIC

Apple saves iPhone photos as HEIC because the format keeps good image quality in a smaller file. Windows itself has no built-in HEIC decoder: the operating system relies on the HEIF Image Extensions package from the Microsoft Store for decoding, and separate video codecs for HEVC video. Even after installing those, plenty of Windows programs, web forms and older apps still expect JPG — which is why converting a copy is usually the practical answer.

Method 1: HEIC Glide in your browser (no install)

  1. Open HEIC Glide in Microsoft Edge, Google Chrome or Firefox on Windows 11.
  2. Select your HEIC photos. Choose one or several files ending in .heic or .heif, or drag them into the converter area.
  3. Download the JPGs. When a file is ready, select Download. Your original HEIC photos stay exactly as they are.

This is the only method here that needs no software installation, no Microsoft account and no admin rights, which makes it the sensible choice on a locked-down work PC.

Method 2: Photos app with the HEIF extension

  1. Install HEIF Image Extensions from the Microsoft Store (free). Without it, Windows cannot decode HEIC at all and you will see "It looks like we don't support this file format".
  2. Open the photo in the Photos app. Double-click the HEIC file.
  3. Save a copy as JPEG. Use the ... menu → Save a copy (or Save as), then choose JPEG in the file type list and save it next to the original.

Note: the HEIF Image Extensions package is free; the separate HEVC Video Extensions package (needed for HEVC video playback) is paid. For still photos you normally only need the free HEIF extension.

Method 3: PowerToys Image Resizer (batch, right-click)

  1. Install Microsoft PowerToys from the Microsoft Store or GitHub.
  2. Select your HEIC files in File Explorer.
  3. Right-click → Resize with Image Resizer. Choose an output format of JPEG and a size, then convert.

PowerToys needs the HEIF extension installed to decode the files, but it is the most convenient way to convert a whole folder from the right-click menu.

Method 4: ImageMagick from the command line (advanced)

If you are comfortable with PowerShell and convert files regularly, ImageMagick handles folders in one line:

magick mogrify -format jpg -quality 90 *.heic

Install it with winget install ImageMagick.ImageMagick. Run it in a copy of the folder while you are learning the command — mogrify writes new files but it is unforgiving of typos.

Common Windows 11 problems

  • "It looks like we don't support this file format" — the HEIF Image Extensions package is missing. Install it from the Microsoft Store, or convert in the browser.
  • No thumbnails in File Explorer — the same missing extension. Thumbnails appear after it is installed and Explorer restarts.
  • The photo opens but a website rejects it — the site only accepts JPG or PNG. Convert a copy and upload that.
  • Colours look different on Windows — iPhone photos use a wide-gamut colour profile that some Windows software handles poorly. Compare the JPG with the original before converting a large batch.
  • The converted file is much larger — normal. HEIC compresses more efficiently than JPEG at similar visible quality.

Stop new iPhone photos from being HEIC

On the iPhone, go to Settings → Camera → Formats and choose Most Compatible. New photos are saved as JPG from then on. Existing HEIC photos are unaffected. More detail in why iPhone photos are HEIC.

Frequently asked questions

How do I convert HEIC to JPG on Windows 11 without installing anything?

Use a browser-based converter. Open HEIC Glide in Edge or Chrome, select your HEIC files and download the JPGs. Nothing is installed and no account is needed.

Can Windows 11 open HEIC files?

Only after the free HEIF Image Extensions package from the Microsoft Store is installed. Even then, specific websites and applications may still require JPG.

Is the HEIF Image Extensions package free?

Yes. The still-image HEIF extension is free; the separate HEVC Video Extensions package for video playback is paid.

Can I convert multiple HEIC photos at once on Windows?

Yes. The browser converter accepts multiple files, and PowerToys Image Resizer converts a whole selection from the right-click menu.

Will converting delete my original photo?

No. Conversion creates a new JPG file. The original HEIC stays on your PC unless you delete it yourself.

Why is the JPG bigger than the HEIC file?

HEIC compresses photos more efficiently than JPEG. A high-quality JPG often uses two to three times the storage for the same visible quality.

Does converting on Windows reduce quality?

JPEG is lossy, so there is a small loss. At high quality it is not visible in normal photos. Convert once from the original file rather than converting an already-converted copy.
