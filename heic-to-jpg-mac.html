How to convert HEIC to JPG on Mac

Use Preview or HEIC Glide to create a compatible JPG copy without installing unfamiliar software.

Quick answer: Open the image in Preview, choose File → Export, select JPEG, adjust quality, and save.

Use Preview to convert HEIC to JPG

Preview is included with macOS and can export images in several formats. It is a dependable option when you want a local desktop workflow.

1. Open the HEIC image

Double-click the HEIC file. If another app opens, Control-click the file and choose Open With → Preview.

2. Choose File → Export

In Preview, open the File menu and choose Export. Choose JPEG from the Format menu. JPEG and JPG refer to the same image format.

3. Pick a quality level and save

Move the Quality control toward Best when image quality matters. Choose a name and location, then click Save. Keep the original HEIC file as your master copy.

Apple documents this workflow in Convert image file types using Preview on Mac.

Convert multiple HEIC photos

For a browser-based batch workflow, open HEIC Glide, select several HEIC or HEIF files, and download each JPG when it is ready. Processing is designed to happen locally in the browser.

Frequently asked questions

Can Preview convert HEIC to JPG?

Yes. Use File → Export and select JPEG.

Will the original HEIC be deleted?

No. Exporting creates a separate JPEG file. Keep the original if you may need to edit or reconvert it later.
