How to convert HEIC to JPG on Mac

Six working methods for macOS — Preview, Photos, Finder Quick Actions, Shortcuts, Terminal and a browser converter — with the steps, the quality settings and the trade-offs of each.

Quick answer: open the HEIC file in Preview, choose File → Export, set the format to JPEG, pick your quality, and save. For batches, the fastest options are Finder Quick Actions (macOS Monterey or later) or the HEIC Glide browser converter, which needs no install.

Method 1: Preview (built into every Mac)

  1. Open the HEIC image. Double-click the file. If another app opens it, Control-click the file and choose Open With → Preview.
  2. Choose File → Export. In Preview, open the File menu and choose Export. In the Format menu, select JPEG. JPEG and JPG are the same format — the extension does not matter.
  3. Pick a quality level and save. Move the Quality slider toward Best when image quality matters. Choose a name and location, then click Save. Keep the original HEIC file as your master copy.

To convert several photos at once in Preview: select all the HEIC files in Finder, Control-click, choose Open With → Preview, select every image in the sidebar, then choose File → Export Selected Images and set the format to JPEG.

Method 2: Photos app (for images in your library)

  1. Select the photos. Open Photos, then Command-click to select one or several images.
  2. Choose File → Export → Export Photos. A dialog opens with the export options.
  3. Set Photo Kind to JPEG. Choose JPEG, set the quality to High or Maximum, decide whether to include the filename, location and IPTC metadata, then click Export.

Careful: Export Unmodified Original is a different command. It exports the original HEIC file, so the result will still be a HEIC — use Export Photos when you need a JPG.

Method 3: Finder Quick Actions (macOS Monterey and later)

  1. Select one or more HEIC files in Finder.
  2. Right-click and open Quick Actions. On a trackpad this is a two-finger click.
  3. Choose Convert Image, then select JPEG and a size (Small, Medium, Large, Actual Size).

The converted copy appears in the same folder as the original. This is the quickest way to convert a handful of files without opening an application.

Method 4: Shortcuts app (repeatable and automatable)

  1. Open Shortcuts and create a new shortcut.
  2. Add the action "Convert Image", then set Format to JPEG and choose the quality.
  3. Add "Save File" (or "Save to Photos") and turn off "Ask Where To Save" if you want it to run unattended.
  4. Run it on a selection from Finder, the Share Sheet, or a Quick Action.

Shortcuts is the best option when you convert the same way every week — build it once, then right-click and run.

Method 5: Terminal with sips (built into macOS)

The sips tool converts images from the command line, which makes it ideal for large folders:

sips -s format jpeg photo.heic --out photo.jpg

Set the JPEG quality (0–100) with formatOptions:

sips -s format jpeg -s formatOptions 90 photo.heic --out photo.jpg

Convert every HEIC file in a folder:

for f in *.heic; do sips -s format jpeg -s formatOptions 90 "$f" --out "${f%.heic}.jpg"; done

Change into the folder first with cd, and check that the loop matched files before you delete anything. The originals are never modified — sips writes new files.

Keeping quality: what actually happens in the conversion

  • HEIC to JPEG is not lossless. JPEG uses lossy compression, so a converted file cannot be mathematically identical. The practical goal is no visible loss, which a high quality setting achieves for normal photos.
  • Use the original file. Do not convert a screenshot, a file that has already been through a messaging app, or a JPG you resaved twice. Each extra export removes detail.
  • Export once. Convert from HEIC to JPG a single time, then share copies of that JPG. Repeated open-and-save cycles add compression artifacts.
  • Expect a larger file. HEIC stores photos more efficiently, so the JPG is often two to three times bigger at the same visual quality. That is normal.
  • Watch the colour profile. iPhone photos are usually captured in Display P3. If a converter drops the colour profile, reds and skin tones can look flat or slightly different in older software. Compare a converted photo with the original before converting an important batch.

Troubleshooting on Mac

ProblemWhat to do
Preview will not open the fileCheck the file extension is .heic or .heif. Files with no extension can be renamed in Finder (turn on "Show all filename extensions" first).
The exported JPG looks washed outThe colour profile was dropped during conversion. Try Preview export or sips instead of a web tool, and compare against the original.
Quick Actions has no "Convert Image"That action requires macOS Monterey (12) or later. Use Preview export or the browser converter instead.
The JPG is much bigger than the HEICExpected. Lower the JPEG quality slightly (around 80–90) if file size matters more than the last bit of detail.
Photos exports HEIC instead of JPGYou used Export Unmodified Original. Use File → Export → Export Photos and set Photo Kind to JPEG.
Metadata or location is missingSome converters keep EXIF data and some strip it. If date, camera details or location matter, check one converted file before converting a whole library.

Stop new iPhone photos from being HEIC

On the iPhone: Settings → Camera → Formats → Most Compatible. New photos are then saved as JPG. This does not change photos you have already taken — those stay HEIC until you convert them. More detail in why iPhone photos are HEIC.

Frequently asked questions

How do I convert HEIC to JPG on Mac for free?

Use Preview: open the file, choose File → Export, select JPEG, then Save. Preview is built into macOS, so nothing needs to be installed or purchased.

Can I convert multiple HEIC files at once on a Mac?

Yes. Select the files in Finder, open them together in Preview, select all images in the sidebar and use File → Export Selected Images. Finder Quick Actions, Shortcuts, the Terminal loop above and the browser converter all handle batches too.

Does converting to JPG reduce quality?

Slightly, because JPEG is a lossy format. At a high quality setting the difference is not visible in normal photos. Convert once from the original HEIC and keep the original file.

Will I lose the original HEIC file?

No. Every method on this page writes a new JPG and leaves the HEIC file untouched. Deleting the originals is always your choice.

Is HEIC the same as HEIF?

HEIF is the container format and HEIC is the variant that holds HEVC-compressed images, which is what Apple uses. On a Mac you will see both extensions and both convert the same way.

Why does the Mac open HEIC but Windows will not?

macOS supports HEIC natively; Windows needs the free HEIF Image Extensions from the Microsoft Store, and some apps still reject the format. See the Windows 11 guide.

Can I convert HEIC to JPG without uploading my photos?

Yes. Preview, Photos, Quick Actions, Shortcuts and sips all work entirely on your Mac. The HEIC Glide converter is also designed to process files inside your browser rather than uploading them.

Does converting keep the photo's date and location?

Usually yes with macOS built-in tools, which carry EXIF metadata into the JPG. Some browser converters strip metadata, so verify one file if date or location matters.
