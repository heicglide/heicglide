What HEIC actually is

  • HEIF is the container format — High Efficiency Image File Format, based on the ISO BMFF standard that MP4 also uses.
  • HEIC is the variant Apple uses: HEIF containing images compressed with the HEVC codec (the same compression family used for 4K video).
  • JPG/JPEG is the older, universally supported format using DCT compression from 1992.

Because HEIF is a container rather than a single image format, one HEIC file can also hold several images — which is how Apple stores parts of a Live Photo and depth information from Portrait mode.

Why Apple switched to HEIC

Apple made HEIC the default when iOS 11 shipped in 2017. The reason is storage efficiency: at similar visible quality, HEIC files are typically about half the size of a JPEG. For a 64 GB iPhone, that difference is the space for thousands of extra photos, and it also reduces iCloud storage and upload time.

Why compatibility problems still happen

HEIC support is not universal, and the gaps are exactly where people need to send photos:

This is why a photo can look perfect on the iPhone it came from and still fail on a work laptop, an online application form or an older photo editor.

Does converting break anything?

  • Live Photos: a JPG export keeps the still image but not the motion. Keep the original HEIC if you want the Live Photo intact.
  • Portrait depth data: the depth map is not carried into a standard JPG, so background blur can no longer be re-adjusted after conversion.
  • Metadata: date, camera details and location survive in most desktop converters but are often stripped by browser tools and messaging apps.
  • Storage: the JPG is usually larger than the HEIC it came from, so converting an entire library needs free space.

Frequently asked questions

What does HEIC stand for?

High Efficiency Image Container — a HEIF file containing images compressed with the HEVC codec. Apple uses the .heic extension; some cameras and Android phones write .heif.

Is HEIC better than JPG?

Technically yes for storage efficiency: about half the file size at similar visible quality, plus support for features such as multiple images and depth data. JPG is better for compatibility, which matters more when you need to share a photo.

Should I switch my iPhone to Most Compatible?

Only if you regularly send photos to Windows users, upload them to forms that reject HEIC, or use older editing software. Otherwise High Efficiency saves a lot of storage, and converting the occasional photo takes seconds.

Will Apple stop using HEIC?

There is no sign of that. Apple continues to use HEIF/HEVC and the wider industry is moving toward newer efficient formats rather than back to JPEG. Compatibility work will keep falling to conversion tools.

Does iCloud convert HEIC to JPG?

Not as a rule — iCloud keeps the original HEIC. Some download and import flows deliver a JPEG copy, which is why the same photo can arrive in different formats depending on how you transferred it. Check the file extension if the format matters.

Is HEIC the same as HEIF?

HEIF is the container; HEIC is the HEVC-based variant Apple uses. Both extensions convert the same way, and both tools on this site accept either.

Why is my photo .HEIC on the phone but .JPG after emailing it?

Mail and most messaging apps re-encode photos when sending them, which is why the recipient gets a JPG. That copy is compressed and usually loses metadata, so it is not a substitute for converting the original.
